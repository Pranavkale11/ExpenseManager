Personal​‍​‌‍​‍‌​‍​‌‍​‍‌ Expense Manager in Java

This console java application is very simple and is used by the users to keep track of their income and expenses.

Every transaction is saved in a CSV file, and the application offers monthly summaries and category-wise reports.

Features

- Add Income

- Add Expense

- View All Transactions

Monthly Summary

- Category-wise Summary

- Automatic CSV storage

## How to Run

1. Open terminal inside the `src` folder:

2. Compile all the Java files: javac *.java

3. Run the program: java Main
